The problem we are solving

Long-running AI assistants must remember what users said weeks ago — without resending entire chat logs every time.

When memory is done poorly, three things go wrong:

  • Wrong answers — the model never sees the right fact, or sees an outdated one.
  • Contradictions — the user corrects themselves (“I moved to Seattle”), but old facts (“lives in Boston”) still appear in memory.
  • Runaway cost — pasting full transcripts into every request burns tokens, money, and latency.

LoCoMo is an independent benchmark that stress-tests these failures using real long conversation data.

Why this drives adoption

Different buyers buy for different reasons — this benchmark supports each with evidence:

  • Platform teams cutting LLM spend — 82% recall at ~1,750 tokens vs ~20,500 for transcript replay; agents run longer without linear cost growth.
  • Products where user truth changes — profiles, preferences, compliance; superseding memory fixes “the bot still thinks I live in Boston.”
  • Long-horizon agents — support, coaching, CRM, personal assistants over weeks; strong open-domain and temporal scores on LoCoMo-length histories.
  • Teams that need honest numbers — fair methodology (per-conversation ingest, session isolation); we show where we beat the industry reference and where we do not yet.
  • Regulated or high-trust domains — provenance and review paths; ContradictionBench complements LoCoMo for memory that corrects itself.

Bottom line for a non-technical reader: Condensate is a credible, cost-efficient memory layer on a hard public test — not at every leaderboard point yet, but strong on price-performance, factual breadth, and timelines, with a clear path on the last few accuracy points.
